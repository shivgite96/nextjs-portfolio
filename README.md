# 🌐 Personal Portfolio — [Live Demo](https://nextjs-portfolio-u3fx.vercel.app/)

Welcome to my personal portfolio website!  
This project showcases my skills, projects, achievements, and background as a **Mechanical Engineer** passionate about **AI, technology, and innovation**.

---

## 🚀 Overview

This portfolio is built using Next.js to provide a fast, modern, and responsive user experience.  
It represents my journey as a student, developer, and innovator — highlighting projects, technical skills, and career milestones.

---

## 🛠️ Tech Stack

- Frontend Framework: Next.js 14 (React-based)
- Styling:Tailwind CSS
- Deployment:Vercel
- Icons:Lucide Icons / Font Awesome
- Animations:Framer Motion
- Version Control: Git & GitHub
